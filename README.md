# STX Token Contract
A standard fungible token contract compatible with STX-based ecosystem
applications.

## Key Functions
- `mint` — Creates new tokens (admin only)
- `transfer` — Moves tokens between wallets securely
- `balance-of` — Queries account balances
- `total-supply` — Returns the total minted tokens

Designed for use in DAOs, DeFi platforms, rewards, and payment systems.
